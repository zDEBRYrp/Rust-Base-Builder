# Источники 3D-моделей

Для новых объектов сейчас используются лёгкие процедурные модели Three.js, чтобы проект не зависел от чужих игровых ассетов.

При поиске готовых моделей найден официальный набор [Facepunch RustRelay.Assets](https://github.com/Facepunch/RustRelay.Assets). В его README указано, что модели предназначены для reference/tooling и должны использоваться согласно TOS Facepunch. Поэтому ассеты оттуда не копируются в этот репозиторий без отдельной проверки разрешений.

Когда будет выбран лицензированный набор GLB/CC0, его можно подключить в `public/models`, не меняя JSON-формат и названия моделей `ShotgunTrap`, `AutoTurret`, `FlameTurret`, `SAMSite` и `VendingMachine`.
